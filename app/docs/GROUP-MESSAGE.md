# Message to share with the group

Hi everyone, the local MarkSync app now supports projects, folders, document moves, Trash/restore and sharing links with either read-only or editing access. Recipients sign in to accept an invitation. Project links cover all its documents; document links cover just one. Owners can revoke links.

There is also a first Yjs live-editing implementation: Markdown edits merge between connected users and save automatically. Titles save separately. This goes beyond Task 1's required presence/heartbeat, so we should review and understand it together rather than claiming a complete production collaboration platform.

Please read README.md for startup, docs/COLLABORATION.md for the current access and editing rules, and docs/VALIDATION.md for tested behaviour. The older Task 1 architecture/theory documents are useful background but their everyone-can-edit policy and future-CRDT statements have been superseded by this extension.
